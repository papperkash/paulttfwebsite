Who it is for

One workflow with a number on it.

This is for the firm that can name the workflow and the KPI. Password resets that still land on the office manager. A phone line that should take the first pass. A Teams question the MSP answers twenty times a week.

It is one production agent. The record includes a live Teams agent, voice agents, and n8n / LangChain. That is the craft. The offer is still one workflow.

If you want a programme with a slide for every department, wait. Start with the job that already has a number.

The engagement

Build one. Measure it. Stop.

We sit with the people who run the workflow today and we write the KPI before we build. Then we put one agent into production: a Teams bot, a voice front door, or an automation that already earns its keep.

Then we stop. You keep the runbook. If the first one earns its keep, we can talk about the next. That is a new conversation.

The Head of IT retainer can own the agent after, if the seat is still empty. The agent offer itself ends when the KPI has an owner.

What you leave with

One thing live.

  • A production agent

    In Teams, on the phone, or on the workflow you named.

  • One KPI

    A number the board can see at the end of the sprint.

  • A runbook

    How it runs, who it escalates to, and what to do when it fails.

  • A stop date

    The offer ends. You decide whether a second agent is worth it.

Questions an FD asks

Before you book.

What is a production IT agent here?

A Teams bot, a voice front door, or an automation that does one job in the live estate. The record uses n8n / LangChain where that is the right tool.

What KPI do you mean?

A number you already care about. Time to first response. Tickets that never reach a person. Calls that no longer sit on reception.

Can we do three agents?

This offer is one. If the first earns its keep, we can talk about the next.

Do you train a model on our data?

Only if the workflow needs it, and only inside the tenant controls we have already agreed. Most of the work is the workflow and the KPI.

Who supports it when you leave?

You do, with the runbook. The Head of IT seat can keep it if you want us in the room.

Can it answer the phone?

A voice front door is one of the three shapes. It takes the first pass. A person still owns the exception.
